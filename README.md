# Internal artifacts for Reports section on the website

https://www.taran.space/reports

## How to publish new report

1. The audit repo has to be a fork of https://github.com/taran-space/template-audit
2. The `DEPLOY_KEY` secret has to be declared in the Environment of the audit repo.
3. The key is in custody of the Product Manager.
4. Check that HTML and PDF versions of the report build and look good.
5. Once the report PR is merged into `main`, it will be automatically pushed into this repo.
